Prompt Engineering Lab

Project Overview

This project explores how prompt design affects the quality of Generative AI responses.

Objective

To compare basic prompts with improved prompts across five business tasks and evaluate the results.

Experiments

Professional Email Writing

Business Report Summarization

Job Description Skill Extraction

Customer Feedback Classification

Structured Table Generation

Tools Used

ChatGPT

Notepad

GitHub

Methodology

For each task, I created a basic prompt and an improved prompt, tested both, compared the outputs, and evaluated the results using predefined criteria.

Evaluation Criteria

Relevance

Accuracy

Completeness

Instruction Following

Format Consistency

See evaluation-results.md for the actual scores and observations.
